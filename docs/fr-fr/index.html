Captures d'écran
Téléchargez et essayez-le maintenant !

Tunalog peut fonctionner sur de nombreux systèmes d'exploitation. Vous pouvez visiter la page des releases GitHub pour voir les différentes architectures disponibles (par exemple, x86, x64 ou ARM).

Télécharger la dernière version de Tunalog sur GitHub:
$ wget -c https://github.com/caris-events/tunalog/releases/latest/download/tunalog_linux_x64
Exécuter le programme principal téléchargé:
$ ./tunalog_linux_x64

(Ou lancer avec l'argument -p :8123 pour changer le port）

Ouvrez votre navigateur et rendez-vous sur le site http://localhost:8080 pour commencer à l'utiliser.

Fonctionnalités basique du blog
Éditeur Markdown simple (alimenté par SimpleMDE).
Thèmes de base personnalisables.
Facile à migrer
Base de données SQLite portable et sans configuration.
Utilise des URL relatives, de sorte que les liens
restent valables en cas de changement de domaine.
Léger et multiplateforme
Prend en charge Linux, Windows et macOS (y compris ARM).
Sa taille n'est que de 30 MiB et il utilise 32 MiB
de mémoire en cours d'exécution.
